## Funções e comportamentos para possível reaproveitamento

### Home anterior

| Função ou estrutura | Finalidade preservada |
| --- | --- |
| `aboutSections` e `technologies` | Conteúdo organizado em dados, separado da renderização. |
| `selectAbout` | Solicita a troca de tópico, ignora seleção repetida e inicia a transição. |
| `handleAboutTransitionEnd` | Coordena fechamento/abertura do conteúdo, troca o tópico e retorna o scroll ao início. |

| `handleAboutTabKeyDown` | Navegação das abas por setas, Home e End, com foco na aba escolhida. |
| `hoveredStack`, `focusedStack` e `activeStack` | Exibe descrições da stack por mouse ou teclado. |

### Autenticação anterior

| Função ou comportamento | Finalidade preservada |
| --- | --- |
| `sendAuthRequest` | Requisição JSON de login/cadastro, tratamento de respostas e mensagens por campo, com cancelamento. |
| `openPanel`, `closePanel` e `changeView` | Abertura/fechamento do painel, alternância de formulário e limpeza dos estados. |
| `handleSubmit` | Validação do formulário, cadastro seguido de login, bloqueio de requisições concorrentes, timeout de 15 segundos e tratamento de falhas. |
| `handleKeyDown` | Fecha com Escape e mantém a navegação por Tab dentro do painel. |
| Efeitos de foco e `inert` | Bloqueiam interação com o fundo, controlam o scroll e restauram foco ao fechar. |
| Efeitos com `element.animate` | Animam a mudança de posição/tamanho do painel e a entrada dos campos. |
| Limpeza com `AbortController` | Cancela requisições ao fechar ou desmontar o componente. |

async function sendAuthRequest(
  endpoint: "login" | "usuarios",
  data: { username: string; password: string; email?: string },
  signal: AbortSignal,
): Promise<Record<string, unknown>> {
  const response = await fetch(`${apiUrl}/${endpoint}/`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    credentials: "omit",
    body: JSON.stringify(data),
    signal,
  });
  const result: unknown = await response.json().catch(() => null);
  signal.throwIfAborted();

  if (!response.ok) {
    if (response.status >= 500) {
      throw new Error("O servidor está indisponível. Tente novamente em instantes.");
    }

    const labels: Record<string, string> = {
      username: "Nome de usuário: ",
      email: "E-mail: ",
      password: "Senha: ",
      non_field_errors: "",
      erro: "",
      detail: "",
    };
    const messages = result && typeof result === "object"
      ? Object.entries(result).flatMap(([field, value]) => {
          if (!Object.hasOwn(labels, field)) return [];
          const errors: unknown[] = Array.isArray(value) ? value : [value];
          return errors
            .filter((error): error is string => typeof error === "string")
            .map((error) => `${labels[field]}${error}`);
        })
      : [];

    throw new Error(messages.join(" ") || "Não foi possível concluir a solicitação. Tente novamente.");
  }

  if (!result || typeof result !== "object" || Array.isArray(result)) {
    throw new Error("O servidor retornou uma resposta inválida. Tente novamente.");
  }

  return result as Record<string, unknown>;
}
